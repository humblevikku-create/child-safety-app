# 🛡️ Child Safety App

Parental monitoring Android app built with Java.

## Features
- SMS/Call tracking
- Location monitoring
- App lock
- Screen time
- SOS alerts
- Remote commands via Socket.IO

## Build

This project auto-builds via GitHub Actions.

1. Push code to `main` branch
2. Go to Actions tab
3. Download APK from Artifacts

## Setup

Add your server URL in `app/src/main/assets/pairing.json`
